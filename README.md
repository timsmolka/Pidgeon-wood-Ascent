# Pidgeon-wood-Ascent

**Crew's Goals**: a daily and weekly goal tracker website.

- **Daily:** 20 push-ups, 20 V-ups, 5-minute doorway stretch (built-in timer), 20-step posture walk
- **Weekly missions:** eye contact + smile, invite a buddy over for the weekend, invite a buddy to lunch 3×

**Level 1 ($10 reward):** reach running totals of 100 push-ups, 100 V-ups, 20 min of doorway stretch, 100 posture-walk steps, 1 eye contact + smile, and either 1 weekend invite or 3 lunch invites.

Build a streak, and check off past days from the week strip. Progress saves in the browser on whatever device it's opened on.

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → deploy from branch `main`, folder `/root`).
